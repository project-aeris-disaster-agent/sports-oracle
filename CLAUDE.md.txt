## What this project is

**Sports Oracle** is a sports data middleware platform. It sits between the Sportradar production API and AI agents/consumers, caching data in Supabase and serving it via a REST API and MCP server. Users stake `$DARE` tokens on Base to get API access. The staking contract is already deployed.

The core value: AI agents get cheap, fast sports data. We protect a 100K/month Sportradar token budget by being cache-first and only calling Sportradar when data is genuinely stale or live.

| Layer | Technology |
|---|---|
| Framework | Next.js 14 App Router (TypeScript) |
| Database + Auth | Supabase (Postgres, RLS, server functions) |
| Frontend auth | Privy (wallet + email login) |

| Blockchain reads | viem (read-only, Base mainnet) |
| Hosting | Vercel (hobby/free tier) |
| Background jobs | GitHub Actions (cron) |
| Sports data | Sportradar (one API key, all sports) |
| Chain | Base mainnet (chain ID 8453) |

No Railway. No separate backend server. No persistent processes.
Everything is either a Vercel serverless function or a GitHub Actions job.

## Database schema (Supabase)

Six tables. All migrations are in `supabase/migrations/` and have been run.

### `users`
Created on first Privy login. `privy_id` is the Privy user ID. `wallet` is lowercase Base address.

### `staker_sessions`
One row per wallet. `expires_at = verified_at + 5 minutes`. The gateway checks this before going on-chain. `tier` is one of: `none`, `scout`, `analyst`, `oracle`.

### `api_keys`
`key_hash` = SHA-256 of raw key (raw key never stored). `key_prefix` = first 12 chars shown in dashboard. `sport_mask` = text array e.g. `['nhl','nfl','mma']`.

### `sports_cache`
`cache_key` pattern: `{sport}:{data_type}:{qualifier}` e.g. `nhl:scores:2025-01-15`. `payload` = raw Sportradar JSON. `expires_at` drives freshness.

### `sportradar_budget`
One row per calendar month. `calls_made` increments on every Sportradar call. At 90K calls, `cache_only` flips to true and the dispatcher stops calling Sportradar until next month.

### `usage_log`
One row per API request. `cache_hit = true` means Sportradar was not called. Auto-cleaned after 90 days.

### Server functions (called via `supabase.rpc()`)
- `verify_api_key(raw_key)` — hashes key, returns key metadata
- `get_cached(cache_key)` — returns payload if not expired, null if stale
- `upsert_cache(...)` — insert or update a cache entry
- `increment_budget()` — atomic counter, returns false if budget full
- `check_budget()` — returns true if calls are still allowed
- `log_request(...)` — fire-and-forget usage logging
- `cleanup_expired_cache()` — deletes rows expired > 24h ago
- `cleanup_old_usage_logs()` — deletes usage_log rows > 90 days

## Auth flow (Privy → Base → API key)

1. User logs in via Privy (wallet or email)
2. User selects sports they want access to
3. Frontend shows required $DARE stake for their selection
4. User stakes via the staking contract UI (already deployed)
5. `POST /api/auth/verify-stake` — reads `getStake(wallet)` from Base contract via viem
6. Result cached in `staker_sessions` (5-min TTL)
7. `POST /api/auth/keys/create` — generates `sk_live_...` key, stores SHA-256 hash in `api_keys`
8. Key shown to user once — not stored in plaintext anywhere

## Gateway middleware (every `/api/v1/*` request)

Located at `src/middleware/gateway.ts`. Call it first in every route handler:

```ts
const auth = await gateway(req, sport)
if (auth instanceof NextResponse) return auth
const { context } = auth
// context.keyId, context.userId, context.wallet, context.tier, context.sportMask
```

Order inside gateway:
1. Extract `X-Oracle-Key` header
2. `verify_api_key()` via Supabase RPC
3. Rate limit via Upstash (tier-based sliding window)
4. Sport access check (`sport_mask.includes(sport)`)
5. Update `last_used_at` (non-blocking)

## Sportradar client (`src/lib/sportradar.ts`)

All Sportradar calls go through `fetchSportradar()` or `fetchAndCache()`. Never call Sportradar directly from a route handler.

Key rules:
- 7s fetch timeout (Vercel hobby limit is 10s)
- Always checks `check_budget()` before fetching
- Calls `increment_budget()` after a successful fetch (non-blocking)
- `fetchAndCache()` writes result to Supabase automatically

Cache-first pattern used in every route:
```ts
const { data: cached } = await supabase.rpc('get_cached', { p_cache_key: cacheKey })
if (cached) return cached

const result = await fetchAndCache({ sport, dataType, params }, cacheKey, ttlSeconds)
```

## Critical rules — never break these

1. Never call Sportradar from client-side code. Server routes only.
2. Never store raw API keys. Hash with SHA-256. Show raw key to user once only.
3. Always check budget before calling Sportradar. Use `check_budget()` or go through `fetchSportradar()`.
4. Always call `gateway()` first in every `/api/v1/*` route. No exceptions.
5. Never use `SUPABASE_SERVICE_ROLE_KEY` in client components.
6. Live endpoint is tier-gated. `scout` gets a 403. Check `context.tier` before serving live data.
7. Set fetch timeouts. Vercel hobby = 10s max. All Sportradar calls use 7s timeout.
8. `sport_mask` is always lowercase. `['nhl', 'nfl']` not `['NHL', 'NFL']`.
9. Supabase keep-alive must stay active. Free tier pauses after 1 week idle.
10. `INTERNAL_CRON_SECRET` guards all `/api/internal/*` routes. Always call `guardInternal(req)` first.

## Common patterns

### Standard route handler
```ts
export async function GET(req: NextRequest, { params }: { params: { sport: string } }) {
  const sport = params.sport.toLowerCase()

  const auth = await gateway(req, sport)
  if (auth instanceof NextResponse) return auth
  const { context } = auth

  const cacheKey = `${sport}:scores:${date}`

  const { data: cached } = await supabase.rpc('get_cached', { p_cache_key: cacheKey })
  if (cached) {
    logRequest(context.keyId, context.userId, sport, 'scores', true, latency)
    return NextResponse.json({ data: cached, meta: { source: 'cache' } })
  }

  const result = await fetchAndCache({ sport, dataType: 'scores', params }, cacheKey, ttl)
  return NextResponse.json({ data: result.data, meta: { source: 'sportradar' } })
}
```

### Tier gate
```ts
if (context.tier === 'scout') {
  return NextResponse.json(
    { error: 'Live data requires Analyst tier or above. Stake 50K $DARE to unlock.' },
    { status: 403 }
  )
}
```

### Non-blocking fire-and-forget
```ts
supabase.rpc('log_request', { ... }).then(({ error }) => {
  if (error) console.error('[log]', error.message)
})
```
